# Kilo32 — Kilo Code CLI 7.8.17 для Windows x86 (IA-32)

Полная 32-битная сборка Kilo Code CLI с интерактивным TUI, Node.js 22.23.0 win-x86, локальными зависимостями, KiloProxyPool и официальным Tor Expert Bundle для Windows i686.

## Установка

Требуются Windows 10 x86 (1809+) или совместимая система, PowerShell 5.1 и Git.

```powershell
git clone https://github.com/javidik/Kilo32.git
cd Kilo32
.\install.bat
```

Установщик проверяет SHA-256, распаковывает архив и устанавливает Kilo в `%LOCALAPPDATA%\Programs\KiloCLI`. Права администратора и отдельная установка Node.js не нужны.

Откройте новое окно PowerShell:

```powershell
kilo --no-proxy --version
kilo
```

## Tor и сеть

В этой версии Tor включён **по умолчанию** и запускается вместе с Kilo. Трафик Kilo направляется через локальный KiloProxyPool и Tor SOCKS5h (`127.0.0.1:19050`). Серверные адреса и учётные данные владельца в репозиторий не включены.

- Обычный запуск: `kilo` — Tor включён.
- Запуск без прокси и Tor: `kilo --no-proxy`.
- Принудительно включить Tor: `kilo --proxy`.
- Диагностика: `kilo --proxy --proxy-debug`.

Список мостов загружается из HTTPS feed при первом запуске, кэшируется локально и обновляется по истечении 7 дней. Процесс проверяет feed каждые 6 часов; если список изменился, Tor перезапускается с новыми мостами. При недоступности feed сохраняется последний рабочий список. Самостоятельная выдача приватных мостов BridgeDB не автоматизируется.

## Структура

- `kilo-cli-x86/dist/` — готовый ZIP IA-32 и его SHA-256.
- `kilo-cli-x86/proxy/` — исходники локального прокси, Tor-менеджера и тесты.
- `kilo-cli-x86/BUILD-ARTIFACT.txt` — сведения о сборке и границы проведённых проверок.

Не публикуйте локальный `proxy/config.json`, `config.runtime.json`, `bridge-cache.json` или собственные приватные мосты. В поставляемом архиве используется placeholder пароля локального loopback-прокси; при необходимости измените его в `%LOCALAPPDATA%\Programs\KiloCLI\proxy\config.json`.

## Проверка

Сборка проверена на целостность ZIP, SHA-256, синтаксис JavaScript и тесты локального прокси/парсера мостов. Полная визуальная и клавиатурная проверка TUI, установка и успешное подключение Tor на физической Windows x86 требуют финального теста на реальном ноутбуке.
